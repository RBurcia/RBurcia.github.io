What I'm building now

Two connected efforts, both running on my own server network: a network of AI agents, and the open-weight language models that power them.

In development

Agent Network

A network of AI agents that hand work to each other. Each agent has its own role, and a coordinating layer routes tasks to whichever one is suited for the job.

  • Agents that split up and pass along multi-step tasks
  • Built to automate work end to end, not only answer questions
  • Runs against my own models, so nothing depends on an outside API

Self-Hosted Open-Weight LLMs
